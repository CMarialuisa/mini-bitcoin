# Mini Bitcoin Wallet - Console App & xUnit

[![.NET 10.0](https://img.shields.io/badge/.NET-10.0-512BD4?logo=dotnet)](https://dotnet.microsoft.com/)
[![xUnit](https://img.shields.io/badge/Testing-xUnit-blue)](https://xunit.net/)

## Sobre o Projeto
Aplicação de consola desenvolvida em C# (.NET 10) que simula uma carteira de criptomoedas. Permite a gestão de saldos em BRL e BTC, simulação de mercado, execução de ordens de compra e venda e extração de histórico de transações, validado através de TDD com **xUnit**. O versionamento segue rigorosamente o padrão **Conventional Commits**.

## Como Executar

**Compilar a Solução:**
```bash
    dotnet build
```

**Executar a Aplicação:**
```bash
    dotnet run --project MiniBitcoin.Console/MiniBitcoin.Console.csproj
```

**Executar os Testes Unitários:**
```bash
    dotnet test
```
